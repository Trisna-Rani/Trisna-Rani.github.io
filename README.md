# Trisna Rani Saha — Academic Portfolio

This version follows the dark academic portfolio direction from the supplied reference design: deep navy/black background, purple highlights, warm gold accents, rounded research cards and a visual certificate gallery.

## Profile photo
The Google Drive URL supplied for the latest profile photo could not be fetched in this environment. The URL currently resolves to a DPDC prepaid-meter receipt rather than a profile photograph, so that receipt has NOT been used as the profile image.

The portfolio therefore keeps the previously supplied profile photograph in `assets/images/profile.jpg`. If the intended new photo is uploaded directly to the chat, replace that file with the new photo and no HTML change is required.

## Certificates
The certificate section uses cropped certificate images so the cards show the certificate itself instead of screenshots with phone/UI margins. The original available PDFs are also kept in `assets/docs/`.

Available visual certificates included:
- CADD
- RHB
- RURS
- 3rd ICALS 2025
- EDGE Smart Office Management
- CKH Employability Skills
- GI Tract Workshop
- Nutrition Club

The Human Rights certificate image was not available as a retrievable file, so it has not been fabricated.

## Editing
The HTML, CSS and JavaScript are intentionally formatted over multiple lines for easy manual editing.

Open `index.html` directly in a browser or use VS Code Live Server.
